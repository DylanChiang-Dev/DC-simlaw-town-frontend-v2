## 核心卖点（v4）

1. **你即律师 · 跑完整个诉讼全流程**：咨询、文书、一审、上诉、二审连续推进。
2. **两种参与方式**：AI 全程自动模拟 / 真人扮演律师亲自下场。

## 三、生命周期表达口径

公开视频主文案不必逐一解释所有内部阶段，建议用「完整诉讼生命周期」统领；画面中可展示更细的 MCP 8 阶段。

| 编号 | 阶段 | 说明 |
|------|------|------|
| 01 | 原告咨询 | 接收当事人陈述，追问事实和证据 |
| 02 | 起诉状起草 | 组织诉讼请求、事实理由、证据和法院信息 |
| 03 | 被告咨询 | 对手方咨询由环境内部 Agent 控制 |
| 04 | 答辩状起草 | 对手方文书由环境内部 Agent 控制 |
| 05 | 一审庭审 | 己方律师发言、举证质证和辩论意见 |
| 06 | 上诉状起草 | 对一审裁判提出不服点和二审请求 |
| 07 | 上诉答辩状起草 | 回应对方上诉请求和理由 |
| 08 | 二审庭审 | 完成二审庭审表达 |
